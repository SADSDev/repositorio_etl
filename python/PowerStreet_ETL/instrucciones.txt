****Notas IMPORTANTES (requisitos de pre-instalación)****
⚠️Es necesario tener Python versión 3.12.x  en el equipo, ya que hay librerias que solo son compatibles con esta versión

⚠️Red Wi-Fi requerida durante la instalación y ejecución de los programas.

⚠️programa(s) ETL debe(n) ser ejecutado(s) vía el CMD, PowerShell o tareas programadas pues
   Playwright requiere un entorno con consola y navegador.

⚠️Componente "Microsoft Visual C++ Redistruable x64" necesario para el funcionamiento de la Liberia Playwright se instala aparte de forma manual mediante: https://aka.ms/vc14/vc_redist.x64.exe

⚠️ "pyodbc" (librería de Python de conexión a SQL Server) requiere que el
   "ODBC Driver de SQL Server" esté instalado en Windows. Este componente también se instala de forma manual mediante: https://download.microsoft.com/download/d624e1c6-293b-4d6f-91b8-6e515a5d6a77/amd64/1033/msodbcsql.msi


****INSTRUCCIONES DE INSTALACIÓN DE PRIMERA VEZ****
1.-Copiar la carpeta del proyecto en ubicación de preferencia

2.-Correr instalacion_primera_vez.bat para instalar dependencias

3.-Listo, ya puedes programar la tarea en Windows de los programas ETL para su ejecución diaria/mensual/semanal
Los programas schedulables son aquellos de nomenclatura: "powerstreet_..."
